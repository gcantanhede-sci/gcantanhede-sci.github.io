Privacy Policy — Calendar MCP (personal Google Calendar assistant)

Last updated: 2026-10-08

This is a private, single-user application. It exists solely for my own use with my own Google account; no other user can install or use it (my Google account is the only registered test user).

What data it accesses

My own Google Calendar data — event lists, creating/updating/deleting events, free/busy availability — through the Google Calendar API, after explicit OAuth 2.0 consent.

Why

To let my local AI assistant (Pi, running on my own computer) read and manage my own calendar: scheduling, reminders, and availability checks.

Where the data lives

On my computer only. OAuth tokens are stored locally in the user profile directory. Calendar data is read into local assistant sessions and is never copied to a server, database, or third-party service by this application.

What it never does

No analytics, no advertising, no profiling, no sharing or selling of data. No calendar data leaves my machine through this app.

Revocation

Access can be revoked at any time at https://myaccount.google.com/permissions.
